Diagnosed an intermittent ASUS RX 580 initialization and black-screen fault using Windows Event Viewer, Device Manager, DDU, BIOS/power-state testing, GPU monitoring, and physical PCIe inspection. Identified repeated AMD `amdwddmg` device-start failures, restored GPU detection after PCIe contact cleaning/reseating, verified full-load GPU operation, and documented remaining driver, PCIe, power-state, PSU, motherboard, and GPU-hardware hypotheses using a structured fault-isolation process.
